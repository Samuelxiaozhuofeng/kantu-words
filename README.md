# 看图记词 · Kantu Words

一张图 → AI 自动把图里的物品框出来、配好单词 / 中文 / 读音 → 学习时框依次亮起，看中文提示打单词、听发音、点图。支持英 / 日 / 韩 / 法 / 德 / 西六种语言。

纯前端 PWA，无框架无构建；一个 Cloudflare Pages 函数负责发音。手机 / 电脑浏览器打开即用，可「添加到主屏幕」。

在线试用：https://kantu-words.pages.dev/

## 功能

- **内置课程**：首页「内置课程」标签里有 12 课现成的（卧室、厨房、浴室、客厅、教室、超市、水果摊、衣柜、书桌文具、公园、动物园、交通工具），第一次打开自动放进本机，不填 Key 就能学；标签旁的语种下拉能把 12 课整体换成日 / 韩 / 法 / 德 / 西版（同一套图和框，只换词）；跟自己的课一样可改可删
- **备课**：选这课学哪种语言（英 / 日 / 韩 / 法 / 德 / 西，记住上次选的）；上传图片，或给个主题（「客厅」「冰箱」一个词就行）让 AI 生图——提示词已经固定加了「每种物品只出现一次、分开摆、不要文字、不要人」的规矩；「AI 识别」自动框出物品并生成该语言的单词、中文、读音（英语音标 / 日语假名 / 韩语罗马音）、词性、同义答案；可勾选「生成例句和搭配」让识别一并出句和搭配，或事后点「补例句和搭配」；选中框可改搭配（一行一条，`[boil] the kettle = 烧水`）；可以改词、拖框（方向键微调）、删框、手动加框；没保存就离开会提醒
- **按水平出词**：设置页「学习」里选「我的水平」（基础 / 进阶约 B1–B2 / 高阶约 C1+，出课页顶栏也能切）；进阶以上 AI 列子话题会更专门、画图不再摆沙发电视、识别只标这个水平还不认识的词（用精确叫法、标零件和材质）；自己传图点「AI 识别」也按它来；内置 12 课不受影响
- **AI 生图 / 出课**：新建课程里点「AI 生图」进选题页，不用自己想关键词——12 个大类（家居、厨房、交通、学校……，可以自己再加）点进去 AI 现场列子话题，想钻多细钻多细；也可以直接输入主题画一张；勾几个点「生成 N 课」，后台按设置里的「同时生成几张图」并发画图、自动识别、自动存课，首页看进度、失败可重试；生成的课归到大类文件夹里，首页按文件夹筛选，编辑页也能手动给课分文件夹
- **今天**：首页顶上一张卡告诉你今天该干什么——到期要复习几个词、新学几个（每日新词上限在设置里调，默认 10）、大约几分钟，一个「开始」按钮；旁边是连续学习天数和本周 7 个小点。每个词有记忆状态：新词 → 学习中 1–4 级 → 已掌握（5 级起）；答对升一级，下次复习间隔拉长（1 / 3 / 7 / 14 / 30 / 60 天），答错掉回 1 级明天再考；同一个词一天只计一次，「再来一组」「再练错的」刷不出假进度。「今天」里新词先「过一遍」（框亮起、看词听音，点下一个），再混着到期词考；练法按熟练度自动选（刚认识的四选一 / 听音点图，学习中打单词，掌握了考例句 / 搭配）。答完每题当场显示「↑ 学习中 2 级 · 3 天后再见」；结果页每个词一行升 / 降 / 新学和下次复习时间，外加连续天数。课卡上有掌握进度环和「到期 n」，点「继续」只练这一课的到期词和新词
- **自由练**：课卡上的「自由练」还是原来的六种练法任选——打英文（框亮起，看中文打英文）、听音点图（播发音，点图里对应的物品，出题顺序打乱）、听句子点图（播例句，点图里说到的物品）、选英文 / 选中文（框亮起，四选一，键盘 1–4）、填搭配（看搭配中文和挖空句，打括号里那个词；题单里没有搭配时不出现这个按钮）；中文提示三种模式（一直显示 / 答错后显示 / 不显示）；显示答案（外文 + 音标 + 词性 + 中文 + 例句 + 搭配；这个词还在别的课出现过可点进词视图）、上一个 / 下一个；答完可选「自动下一题」或「答完停住」（停在答案上看，Enter 或点图进下一题）；练习中随时勾「错题本」把当前词收进去；发音 / 答案 / 错题本三个快捷键在设置页可改（默认 Ctrl+' / Ctrl+; / Ctrl+/）；走完出一次答对率，结果页每个词有「错题本」勾选框，勾上 / 取消立即生效
- **已收起**：课卡上点「收起」（一课全部掌握时首页会提示「收起这一课」；自由练整课全对时结果页也有）就收进首页「已收起」标签，不再占「我的课程 / 内置课程」的位置，也**不再催复习**；那里能复习、编辑，点「放回」回原处，到期照常；收起的课里的错词照常留在错题本
- **错题本**：没一次答对的词答完那一刻就记进首页「错题本」（练习中勾选框也能手动收 / 移），按加入时间倒序，每个词一张词卡（图里裁出来的那一块、发音、音标、词性、中文、例句、搭配；点单词进词视图）；答对了不自动移出，在结果页取消勾选或词卡上点「移出」才拿掉，也可清空，或把整本拿来练（顶栏课程名和图随题换课）；已删课程里的词不显示
- **导出到 Anki**：错题本可一键导出到本机 Anki 桌面版（需开着 Anki 并装 AnkiConnect 插件，代码 2055492159；网页连 `127.0.0.1:8765`）。四种卡片：图→词、词→中文、中文→图、双向，笔记类型自动建。可选「导出后清空错题本」（已加入和已存在的会拿掉，失败的留下）
- **再练错的**：结果页可只练本次没一次答对的那几个，练法和提示不变；四选一的干扰项仍从该词所在整课抽
- **判对规则**：不分大小写、忽略冠词（各语种各自的）和标点、AI 给的同义词算对（日语打假名也算对）、单复数（s / es）算对
- **发音**：微软 Edge 朗读（免费、不要 Key），每种语言配好发音人，英语的可换；本地缓存；失败自动降级浏览器自带朗读
- **数据**：全部存在本机浏览器（IndexedDB），图片入库前压到 1600px JPEG；「导出备份」带课程、学习进度、错题本、每日日志，导入时进度按词合并（同一个词保留更新的）；旧版本的纯课程备份照常能导入。删课、内置课切语种会一并清掉对应进度

## 需要准备

只玩内置课程什么都不用准备。要自己传图建课，需要一个 **OpenAI 兼容**的 API 地址和 Key（OpenAI、Gemini 的 OpenAI 兼容端点、各类中转站都行）。识别模型要能看图，推荐 Gemini Flash 系列（框物品坐标准、便宜）。生图可选，模型要支持 `/images/generations`。

Key 只存在浏览器 localStorage，不经过任何第三方服务器；接口没开 CORS 时请求会经你自己部署的 `/proxy` 函数转一手。

## 部署自己的

```bash
npx wrangler login
npx wrangler pages project create kantu-words --production-branch master
npx wrangler pages deploy . --project-name kantu-words --branch master
```

免费额度够个人用。

## 结构

| 文件 | 管什么 |
|---|---|
| `index.html` | 页面壳 + 样式 |
| `app.js` | 路由、课程列表、设置页、导入导出 |
| `editor.js` | 备课页：传图 / 生图 / 识别 / 改框 |
| `gen.js` | AI 出课页：选大类 → AI 列子话题 → 生图 + 识别存成一课；勾选批量 / 并发生成，首页看进度 |
| `study.js` | 学习页：判对、提示、新词先过一遍、按题自选练法、答完写记忆状态 |
| `stats.js` | 统计页：已掌握 / 学习中 / 新词、最近 30 天、练法强弱、最难的词 |
| `progress.js` | 词级学习进度：复习间隔、按熟练度选练法、今天的题单、每日日志与连续天数 |
| `word.js` | 跨课词视图：这个词在各课的出现 |
| `ai.js` | 调 AI：拉模型、识图、生图 |
| `tts.js` | 发音：缓存 → `/tts` → 降级 |
| `anki.js` | 导出到 Anki：AnkiConnect、卡片预设、高亮图 |
| `lib.js` | IndexedDB、设置、小工具 |
| `sw.js` `manifest.json` | PWA |
| `packs/` | 内置课程：`index.json`（词表 + 框）和图片，首次打开导入本机 |
| `functions/tts.js` | Cloudflare 函数：代连 Edge TTS（浏览器不能自己设那些请求头） |
| `functions/proxy.js` | Cloudflare 函数：给没开 CORS 的接口转一手 |

## 已知

- Edge TTS 是微软给 Edge 浏览器内置的非公开接口，没有 SLA；校验规则偶尔会变，403 了先看 `functions/tts.js` 顶上的版本号和 UA
- 识别偶尔重复 / 漏框，编辑页手动改
