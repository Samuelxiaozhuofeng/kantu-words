# 看图记词 · Kantu Words

一张图 → AI 自动把图里的物品框出来、配好单词 / 中文 / 读音 → 学习时框依次亮起，看中文提示打单词、听发音、点图。支持英 / 日 / 韩 / 法 / 德 / 西六种语言。

纯前端 PWA，无框架无构建；一个 Cloudflare Pages 函数负责发音。手机 / 电脑浏览器打开即用，可「添加到主屏幕」。

在线试用：https://kantu-words.pages.dev/

## 功能

**核心想法：每个词都住在一张图里的一个位置上。** 整张图一开始是灰的，学会一样东西，图里那样东西就亮起颜色，越熟越鲜艳；该复习的地方蒙一层灰雾。

- **四个标签**：今天 / 世界 / 词库 / 我（手机上在底部，电脑上在顶栏；学习和编辑时收起，专心做一件事）
- **新手引导**：第一次打开只问两件事——学哪种语言、从哪一档学起（看一行具体的词选「大多还说不出来的那一行」）——然后马上认第一张图里的 3 个词；学完才问「以后每天学几个新词」。不用填 Key
- **今天**：一个「开始」按钮（到期复习 + 每日新词，约几分钟）；连续天数和最近 7 天的点；**冻结卡**：漏掉单独一天自动冻结、不算断（7 天里一次），连漏两天才断；下面是「正在点亮的场景」和「拍一拍」
- **世界**：所有场景（内置 + 自己的）按上色图排开，卡上写「亮起 n / 总数」，全部掌握显示「✨ 集齐」；按内置 / 文件夹 / 已收起筛选；内置课的语种在这里换
- **场景页**：点图里任何东西就读出来、标上名字；「继续学」只学这一课的到期词和新词；四个玩法和专项练；右上角 ⋯ 里编辑 / 收起 / 删除
  - **记忆宫殿**：图暗下来，只剩物品轮廓，从左到右一个个亮框，按位置打出它叫什么；答出来灯就亮
  - **少了什么？**：一样东西被雾遮住，从四个词里选出它
  - **听故事**（要 AI）：AI 看图用这课的词写 5–8 句小故事，一句句读，读到哪句图里那几样东西亮到哪；可看中文，写好的故事存在课里
  - **描述这张图**（要 AI）：写或口述几句话，AI 告诉你用对了哪几个词（图里亮起来）、哪里要改、更地道的说法；用对的词记一次答对
- **学习阶梯：认 → 指 → 拼 → 说 → 用**。每个词有记忆状态：新词 → 学习中 1–4 级 → 已掌握（5 级起），答对升一级、下次复习间隔拉长（1 / 3 / 7 / 14 / 30 / 60 天），答错掉回 1 级；同一个词一天只计一次。练法按熟练度自动选：刚认识的四选一 / 听音点图，学习中打单词，**4 级这一关必须「说出来」才升到已掌握**，掌握后轮换说 / 打 / 句子 / 搭配
- **新词先猜后看**：镜头推近到那样东西，先问「你觉得它叫什么？」，按揭晓才给词、读音和中文；例句和搭配折起来，想看再展开；这个词还在别的图里出现过就摆几张小裁图
- **说出来**：按话筒说，浏览器识别到就自动判（整句里含这个词也算）；识别不可用（Firefox、没麦克风权限、国内 Chrome 连不上谷歌的识别服务）就改成自己判：说出来 → 点「答案」→「我说对了 / 没说对」
- **九种练法**：打单词、听音点图、听句子点图、选单词、选中文、填搭配、说出来、记忆宫殿、少了什么。自由练 / 专项练固定一种，学习页顶上的下拉可换；「今天」每题自带练法
- **结果页**：一次答对几个、每个词的升降和下次复习时间、这一场让哪些场景亮了（灰图慢慢浮出颜色）、错题本勾选、再来一组 / 再练错的
- **答对 / 答错**有提示音和手机轻震（「我 → 学习」里可关）；中文提示（一直 / 答错后 / 不显示）和「答对后自动下一题 / 停住」也在那里改，学习页不再摆开关
- **拍一拍**：拍自己的房间、冰箱、书桌，直接进新建页，填过 Key 就自动框出物品；也可以传图、让 AI 画（「AI 出课」：选大类 → AI 列子话题 → 批量生成，按「我的水平」出词）
- **编辑**：改词、拖框（方向键微调）、删框、手动加框、补例句和搭配；没保存就离开会提醒
- **词库**：已掌握 / 学习中 / 新词、最近 30 天、九种练法的答对率（最弱的可「专练」）、最难的 10 个词、错题本（词卡、练习、导出到 Anki）
- **导出到 Anki**：错题本一键导出到本机 Anki 桌面版（需开着 Anki 并装 AnkiConnect 插件，代码 2055492159）。四种卡片：图→词、词→中文、中文→图、双向
- **判对规则**：不分大小写、忽略冠词（各语种各自的）和标点、AI 给的同义词算对（日语打假名也算对）、单复数（s / es）算对
- **发音**：微软 Edge 朗读（免费、不要 Key），每种语言配好发音人，英语的可换；本地缓存；失败自动降级浏览器自带朗读
- **数据**：全部存在本机浏览器（IndexedDB），图片入库前压到 1600px JPEG；「我 → 备份」导出 / 导入，带课程（含故事）、学习进度、错题本、每日记录；导入时进度按词合并。删课、内置课切语种会一并清掉对应进度

## 需要准备

只玩内置课程什么都不用准备。要自己传图建课，需要一个 **OpenAI 兼容**的 API 地址和 Key（OpenAI、Gemini 的 OpenAI 兼容端点、各类中转站都行）。识别模型要能看图，推荐 Gemini Flash 系列（框物品坐标准、便宜）。生图可选，模型要支持 `/images/generations`。

Key 只存在浏览器 localStorage，不经过任何第三方服务器；接口没开 CORS 时请求会经你自己部署的 `/proxy` 函数转一手。

## 部署自己的

```bash
npx wrangler login
npx wrangler pages project create kantu-words --production-branch master
npx wrangler pages deploy . --project-name kantu-words --branch master
```

免费额度够个人用。

## 结构

| 文件 | 管什么 |
|---|---|
| `index.html` | 页面壳 + 导航 + 样式 |
| `app.js` | 路由、四个标签、「我」页（设置 + 备份导入导出） |
| `home.js` | 今天页、世界页、新手引导 |
| `scene.js` | 场景页：上色大图探索、玩法入口；听故事、描述这张图 |
| `paint.js` | 场景上色：灰底 + 学过的物品按熟练度上色 + 到期蒙灰雾 |
| `study.js` | 学习页：九种练法、判对、新词先猜后看、镜头、说出来 |
| `result.js` | 结果页：上色前后对比、每词升降、错题本勾选 |
| `speech.js` | 浏览器语音识别（说出来、口述） |
| `progress.js` | 词级学习进度：复习间隔、按熟练度选练法、今天的题单、每日日志、连续天数与冻结卡 |
| `stats.js` | 词库页：统计、练法强弱、最难的词、错题本 |
| `editor.js` | 备课页：传图 / 拍一拍 / 识别 / 改框 |
| `gen.js` | AI 出课页：选大类 → AI 列子话题 → 生图 + 识别存成一课；批量 / 并发 |
| `word.js` | 跨课词视图：这个词在各张图里的出现 |
| `ai.js` | 调 AI：拉模型、识图、生图、写故事、点评描述 |
| `tts.js` | 发音：缓存 → `/tts` → 降级 |
| `anki.js` | 导出到 Anki：AnkiConnect、卡片预设、高亮图 |
| `packs.js` | 内置课程：首次放进本机、只填空升级、换语种 |
| `lib.js` | IndexedDB、设置、点图命中、提示音、小工具 |
| `sw.js` `manifest.json` | PWA |
| `packs/` | 内置课程：`index.json`（词表 + 框）和图片 |
| `functions/tts.js` | Cloudflare 函数：代连 Edge TTS（浏览器不能自己设那些请求头） |
| `functions/proxy.js` | Cloudflare 函数：给没开 CORS 的接口转一手 |

## 已知

- Edge TTS 是微软给 Edge 浏览器内置的非公开接口，没有 SLA；校验规则偶尔会变，403 了先看 `functions/tts.js` 顶上的版本号和 UA
- 识别偶尔重复 / 漏框，编辑页手动改
- 语音识别靠浏览器：Chrome / Edge / Safari 有，Firefox 没有；国内网络下 Chrome 的识别常连不上，会自动改成「自己判」
